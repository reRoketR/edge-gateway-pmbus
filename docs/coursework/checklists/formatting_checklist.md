# Formatting Checklist (Methodical Compliance)

## Document-level

- [x] Language is Ukrainian.
- [ ] Total volume is within 30-50 pages.
- [ ] Main sections (1-4) occupy 30-45 pages.
- [ ] Font is Times New Roman, size 14.
- [ ] Line spacing is 1.5.

## Page layout

- [ ] Left margin >= 25 mm.
- [ ] Right margin >= 10 mm.
- [ ] Top margin >= 20 mm.
- [ ] Bottom margin >= 20 mm.
- [ ] Section-start pages use enlarged top margin (recommended 40 mm).

## Pagination and headings

- [ ] Continuous page numbering is applied.
- [ ] Title page has no visible page number.
- [ ] Section headings are formatted and numbered by guideline rules.
- [ ] Figures/tables/formulas are numbered by section.

## References and integrity

- [ ] Every reused method/figure/table has citation `[n]`.
- [ ] No raw copy-paste from sources without proper quoting.
- [ ] Own results are present in all sections and appendices.

## Graphics and appendices

- [x] Functional scheme is present.
- [x] UML diagrams are present.
- [x] Algorithm flowcharts are present.
- [ ] Listings are moved to appendices.
