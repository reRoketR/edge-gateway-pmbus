# Технічне завдання (чернетка)

## 1. Тема

Програмне забезпечення мікрокомп'ютера PMBus-MQTT gateway для збору
телеметрії та передачі даних.

## 2. Підстава для розроблення

Курсова робота з дисципліни «Програмні засоби мікропроцесорних систем».

## 3. Початкові дані

1. Мікрокомп'ютерна платформа: CY8CKIT-062S2-43012.
2. Периферійний інтерфейс: I2C/SMBus (PMBus commands).
3. Комунікація з верхнім рівнем: Wi-Fi + MQTT.
4. Конфігурація профілю (базова): `source/profiles/profile_default.h`.

## 4. Функціональні вимоги

1. Ініціалізація BSP, UART debug та RTOS задач.
2. Періодичне опитування PMBus-пристрою (telemetry + status).
3. Декодування форматів Linear11/Linear16.
4. Формування JSON-повідомлень за topic/payload контрактами.
5. Публікація в MQTT broker з обробкою reconnect.
6. Буферизація повідомлень при офлайн-режимі.
7. Збір і публікація службових метрик продуктивності.

## 5. Вимоги до програмної архітектури

1. Архітектура на FreeRTOS із розподілом на задачі:
   `pmbus_poll_task`, `mqtt_gw_task`, `buffer_task`.
2. Обмін між задачами через черги IPC.
3. Модульний поділ: init/driver/decode/transport/buffer/metrics/events.

## 6. Вимоги до тестування

1. Unit-тести host-side:
   - `test_buffer_ring`
   - `test_pmbus_decode`
   - `test_json_encode`
2. Формальні критерії:
   - `0 failed` для всіх test suites
   - валідація JSON contract
   - перевірка buffering behavior у логах

## 7. Вихідні матеріали

1. Пояснювальна записка.
2. Графічна частина (функціональна/принципова схема, UML, алгоритми).
3. Лістинги програмних модулів у додатках.
4. Електронний пакет до захисту.
