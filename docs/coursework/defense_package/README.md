# Defense Package Assembly Guide

Prepare one folder with Latin naming, for example:

`KI405_SYMANYSHYN`

Recommended internal structure:

```text
KI405_SYMANYSHYN/
  manifest.md
  report/
    coursework_report.docx
    coursework_report.pdf
  source/
    rtos_test/...
  graphics/
    exports/
      functional_electrical_scheme.pdf
      uml_component.pdf
      uml_sequence_pmbus_to_mqtt.pdf
      flow_init_main_to_scheduler.pdf
      flow_polling_loop.pdf

      ...
  evidence/
    host_test_results_2026-03-08.md
    logs_inventory_2026-03-08.md
    screenshots/
      vscode_modustoolbox_debug.png
```

## Mandatory checks before submission

1. Explanatory note is complete and formatted.
2. Graphics are exported to printable format (A3 where needed).
3. Source code is included.
4. File/folder names are Latin-only.
5. All references are present in report text.
